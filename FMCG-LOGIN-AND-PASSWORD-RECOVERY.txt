Login branding revised from ingredient/product-specific wording to DeshiGram FMCG operations branding.

Forgot password flow added using Supabase Auth:
1. Admin enters authorised email.
2. Supabase sends recovery email.
3. Link returns to https://deshigram.in/admin.html?recovery=1
4. PASSWORD_RECOVERY opens secure new-password dialog.
5. New password is saved with auth.updateUser.

Important production setting: in Supabase Auth URL Configuration, https://deshigram.in/admin.html?recovery=1 (or a matching allowed pattern) must be an allowed Redirect URL. Production email delivery should use configured SMTP for reliability.
