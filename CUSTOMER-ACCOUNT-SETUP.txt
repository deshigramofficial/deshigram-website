DESHIGRAM CUSTOMER ACCOUNT SETUP

1) Supabase > SQL Editor > New Query
   Open customer-account-setup.sql, paste all, Run.

2) Supabase > Authentication > Providers > Email
   Keep Email provider enabled.
   Turn OFF "Confirm email" / email confirmation.
   This is required because DeshiGram customer accounts use the customer's mobile number on screen and a hidden internal login identifier; customers do not need to provide or verify an email.

3) Upload the website files to GitHub Pages.

Customer flow after setup:
Product -> Cart -> Checkout -> Login/Create Account -> Payment -> Order saved to My Account -> My Orders -> Rate Product -> Verified Customer review.

Public review forms have been removed. Reviews display in a fixed-height horizontal carousel so the page does not keep getting longer.
